# learn-fde — FDA（前沿部署工程师）三个月成长仓库

目标：2026-11 底前具备济南 AI 解决方案 / 大模型应用 / 智能体应用工程师岗位的面试能力，用 **3 个可演示作品** 支撑简历。

## 仓库结构

```
├── FDA三个月学习计划.md   # 总纲：12 周阶段目标 / 资源清单 / 面试自测题
├── 每日学习计划.md        # 主战场：1h/天 × 84 天逐日执行表（含打卡）
├── notes/                 # 每周周报 week-XX.md + 实验记录
└── app/ 等                # 每周代码产出
```

## 执行规则

- 每天约 1 小时：40 分钟学/动手 + 20 分钟整理提交，**每天至少 1 个 commit**。
- 每周日为机动日：先补欠账，再写周报。
- 打卡在《每日学习计划》里把 ☐ 改 ✅，行尾加一句记录。
- 落后 2 周启用计划文末的「保底方案」，不推翻重来。

## 三个里程碑

| 里程碑 | 时间 | 交付物 |

| M1 | 9.20 | 个人知识库问答服务 + 20 题评估报告 |
