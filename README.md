## 仓库结构

```
├── 三个月上岸计划.md   # 总纲：里程碑 / 砍留清单 / 面试自测 10 题
```

## 执行规则

- 每天至少 1 个 commit；打卡在《每日学习计划》里把 ☐ 改 ✅，行尾加一句记录。
- 每周日先补欠账，再写周报 `notes/week-XX.md`。
- ☕ 人脉动作与写代码同等重要，不占学习时间、不许砍。
- W8 起试探性投递摸风向；有真面试邀约先去面，面完复盘补强。
- 已砍项（ACP 认证、vLLM 深挖、Chatchat 源码精读、LoRA、LangGraph 系统学）**永远不捡回来**。
